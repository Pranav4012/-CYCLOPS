CYCLOPS — a unidirectional-first passive NDR for data-diode enclaves (SIH 2026 · PS 26145 · NTRO). The load-bearing bet: the unseen return half is not missing data, it is an inference target. HalfSight reconstructs it (GHOSTFLOW/PULSE), VANTAGE routes by which half we see, four detector banks work in the timing & information domains, CALIBER makes confidence honest and auditable, and WIRESEAL makes every probabilistic alert court-reproducible.

This console is a live simulation over a scripted scenario for demonstration — the detection maths (spectral periodogram, entropy, backlog estimation, Merkle inclusion proofs) is computed in-page, not pre-rendered. Reference engine reference-impl/halfsight/ runs the same detectors on real flows and on real .pcap captures (python3 -m halfsight.ingest capture.pcap); BABEL's DGA detector is an ML model trained on 25 real DGA families (AUC 0.97), and the pipeline is validated on 8/8 real public attack captures (real DDoS, iodine/dnscat2 tunnels, Slowloris, a real Cobalt Strike C2 beacon). All KPI figures are measured — see the evaluation report ↗.
